# AGENTS.md

Инструкции для ИИ-агентов (Codex / Copilot / ChatGPT), работающих с этим репозиторием.

## 1. Назначение проекта

Это одностраничное веб-приложение (**single-file `index.html`**), которое рисует анимированный снег:

- Снежинки падают по «живой» траектории (ветер, шум, разные скорости).
- При клике/тапе по экрану запускается волна, от которой снежинки «дрожат» и разлетаются.
- Внизу экрана растут **сугробы**, накапливающие снег. Со временем сугробы могут заполнить весь экран.
- Есть **настройки**:
  - Стиль снежинок: ☁️ «Пух» / ❄️ «Снежинка».
  - Интенсивность снега (кол-во снежинок).
  - Размер снежинок.
  - Сила волны.
  - Цвет фона (16 пастельных).
  - Цвет снежинок (16 пастельных).
  - Сброс сугробов.
- Есть кнопка **fullscreen**.
- Всё адаптировано под мобильные/тач-устройства.

Цель: сохранить простоту и «магичность» эффекта, при этом сделать код понятным и удобным для дальнейшего развития.

---

## 2. Общие принципы разработки

Пожалуйста, придерживайся следующих правил:

1. **Весь код — в одном `index.html`.**
   - Не разбиваем на отдельные `.js`, `.css`, и т.д.
   - Можно реорганизовывать структуру внутри файла (секции с комментариями).

2. **Чистый, понятный vanilla JS и CSS.**
   - Без фреймворков и сборки.
   - Без зависимостей из CDN, кроме крайних случаев (и только по прямому запросу).

3. **Никаких «магических» скрытых изменений.**
   - При доработках сохраняем существующее поведение по умолчанию.
   - Новые фичи делаем **опциональными** или хорошо вписанными в текущую UX-модель.

4. **Мобильная адаптивность — приоритет.**
   - Проверять `pointer`-события, не ломать поведение на touch.
   - Не добавлять тяжёлые эффекты, сильно бьющие по производительности на телефонах.

5. **Плавные анимации.**
   - Всё, что анимируется, должно работать через `requestAnimationFrame`.
   - Избегать синхронных блокировок, больших перерасчётов в одном кадре.

## 3. Текущая архитектура (важно для модификаций)

Структура примерно такая (внутри `<script>(() => { ... })();</script>`):

- **Константы и ключи:**
  - `LS_SETTINGS_KEY = "snow_app_settings_v1"`
  - `LS_BANK_KEY = "snow_app_bank_v1"`

- **UI-элементы:**
  - `canvas` для рисования.
  - Кнопки:
    - `#fsBtn` — fullscreen (иконки `#fsIconEnter`, `#fsIconExit`).
    - `#gearBtn` — настройки.
  - Попап/оверлей настроек:
    - `#overlay`, `#popup`, `#closeBtn`.
    - Селект стиля снежинок: `#flakeStyle` (значения `"puff"` и `"flake"`).
    - Палитры цветов:
      - `#bgSwatches` (фон).
      - `#flakeSwatches` (снежинки).
    - Рейнджи:
      - `#countRange` — количество снежинок.
      - `#sizeRange` — размер (в процентах).
      - `#waveRange` — сила волны.
    - Кнопка сброса сугробов: `#resetBanksBtn`.

- **Palettes:**
  - `BG_PALETTE` — 16 пастельных фонов.
  - `FLAKE_PALETTE` — 16 пастельных цветов снежинок.
  - Цвета используются только из этих массивов. При загрузке из `localStorage` значения валидируются — если цвет не из палитры, берётся дефолт.

- **Settings (`settings` объект):**
  - `style: "puff" | "flake"`
  - `count: number` (60–260)
  - `sizeMul: number` (0.7–1.6, хранится как float)
  - `waveAmp: number` (40–140)
  - `bg: string` (HEX, из `BG_PALETTE`)
  - `flake: string` (HEX, из `FLAKE_PALETTE`)

- **Система сугробов:**
  - Масштабирование по X: `bankStep` и `bankN` зависят от ширины окна.
  - `bankBase: Float32Array` — «базовый» рельеф.
  - `bank: Float32Array` — текущие высоты сугроба (база + накопленный снег).
  - При ресайзе:
    - База пересчитывается.
    - Текущий `bank` пересэмплируется (через `resampleArray`) под новый `bankN`.
  - При накоплении:
    - `addToBank(x, amount)` увеличивает высоты в окрестности, потом сглаживает.
    - Нет жёстного лимита: сугробы могут заполнить весь экран.

- **Снежинки:**
  - Массив `flakes` с объектами, содержащими положение, радиус, скорость, фазу, шум и импульсы от волн.
  - Рендер:
    - Стиль `"puff"` — круглые мягкие «пуховые» снежинки.
    - Стиль `"flake"` — 6-лучевые снежинки с веточками.

- **Волны (`waves`):**
  - При `pointerdown` создаётся объект волны (центр, радиус, amр, life).
  - Снежинки получают импульс и «дрожание» при прохождении волны.

- **Сохранение в `localStorage`:**
  - `saveSettingsNow()` / `saveBankNow()` с дебаунсом через `scheduleSaveAll` и `scheduleSaveBank`.
  - Формат настроек:
    ```json
    {
      "v": 1,
      "style": "puff",
      "count": 150,
      "sizeMul": 1,
      "waveAmp": 90,
      "bg": "#0B0F14",
      "flake": "#FFFFFF"
    }
    ```
  - Формат сугроба:
    ```json
    {
      "v": 1,
      "n": <bankN>,
      "step": <bankStep>,
      "w": <canvasWidth>,
      "h": <canvasHeight>,
      "data": [<float heights>]
    }
    ```

## 4. Как ИИ-агенту вносить изменения

### 4.1. Общие правила

- **Не менять схему хранения без необходимости.**  
  Если нужно расширить:
  - Увеличь версию (`v: 2`) и добавь миграцию из старой структуры.
  - Не ломай существующих пользователей.

- **Сохранять совместимость по UI и поведению.**
  - При добавлении новых настроек:
    - Выставь разумные дефолты.
    - Не заставляй пользователя заново всё настраивать.

- **Поддерживать читаемость.**
  - Комментарии приветствуются.
  - Логика, связанная с одной подсистемой (снег, сугробы, UI, localStorage), должна быть сгруппирована.

- **Не добавлять тяжёлые библиотеки.**
  - Если очень нужно — делай это только по явной просьбе и минимально.

### 4.2. Стиль кода

- Использовать `const` / `let`, а не `var`.
- Функции — либо декларации (`function foo() {}`), либо `const foo = () => {}`, но не мешать стили в одном месте без причины.
- Не злоупотреблять глобальными переменными: всё уже обёрнуто в IIFE `(() => { ... })();` — сохраняй этот подход.
- Не подключать TypeScript, Babel и т.п.

## 5. Планируемые/возможные улучшения (подсказки для агента)

Ниже идеи, которые можно делать в будущем. Если пользователь явно попросит — приоритизируй его запрос.

1. **Режимы сцены:**
   - Ночь, сумерки, полярная ночь, мягкий «новогодний» свет и т.п.
   - Можно хранить пресеты (комбо фон + цвет снежинок + интенсивность) и переключать их.

2. **Режим без шлейфа:**
   - Переключатель «Шлейф» (on/off), где при `off` фон перерисовывается полностью, без «ghosting».

3. **Ограничение FPS / энергосберегающий режим:**
   - Например, «Эко-режим» — снижать количество снежинок и частоту обновления на слабых девайсах.

4. **Экспорт/импорт настроек:**
   - Небольшая JSON-строка для шеринга пресетов или состояния сугробов.

5. **Новый тип снежинок:**
   - Например, круглые снежинки с маленьким крестиком внутри или «кристаллы».
   - Добавлять как новый вариант в селект, с эмодзи.

6. **UI-улучшения:**
   - Анимация открытия попапа.
   - Кнопка «Сбросить всё (настройки + сугробы)» — чистит `localStorage`.

## 6. Как лучше взаимодействовать с пользователем

Если ты — интерактивный агент (ChatGPT/Codex в IDE / в ChatGPT):

- При изменениях:
  - Кратко опиши, **что именно** было сделано (1–3 буллет-пункта).
  - Проводи изменения локально, не отдавай полный index.html файл, чтобы не тратить лишние токены.
- Если планируешь крупный рефакторинг:
  - Сначала опиши идею и спроси подтверждение пользователя (в отличие от этого файла в диалоге ChatGPT, здесь это желаемое поведение).
- Если нужно новое хранилище данных:
  - Сначала подумай, можно ли расширить текущую схему `localStorage` без ломания старой.

## 7. TL;DR для агента

- Всё живёт в **одном `index.html`**.
- **Не ломай** текущие настройки и сохранённые сугробы.
- При доработках:
  1. Учитывай `localStorage` (чтение/запись + миграция).
  2. Не убивай производительность, особенно на мобильных.
  3. Сохраняй красивый визуальный стиль и аккуратный код.

Если сомневаешься — сделай консервативное изменение и оставь комментарий в коде с пояснением.
